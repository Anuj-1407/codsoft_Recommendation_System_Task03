# 🎬 CodSoft Movie Recommendation System

An interactive and beginner-friendly **Movie Recommendation System** built using **Python**.  
This project recommends movies based on user-selected genres and allows users to create their own watchlist.

It includes both **Hollywood** and **Indian movies** with ratings for a better experience
## 🚀 Features
✔ Genre-based movie recommendations  
✔ Hollywood + Bollywood movie collection  
✔ Movie ratings display  
✔ Add movies to personal watchlist  
✔ Interactive console interface  
✔ Beginner-friendly Python project  

## 🛠 Tech Stack

- Python
- Lists & Dictionaries
- Loops
- Conditional Statements
- User Input Handling

## 📂 Available Genres

- Action
- Comedy
- Horror
- Sci-Fi
- Drama
